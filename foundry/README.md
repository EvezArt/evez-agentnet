# EVEZ Agentic OS Foundry

The Foundry is the assembly layer above the EVEZ project corpus.

It discovers reusable capabilities, composes candidate operating environments, tests them, preserves evidence, and generates later generations from observed results.

First executable slice:

    python foundry/inventory.py --owner EvezArt
    python foundry/assemble.py "autonomous scientific research"

The generated manifest is PROPOSED. It is not validation.

Architecture:

DISCOVER -> NORMALIZE -> COMPOSE -> BOOT -> PROBE -> BREAK -> REPAIR -> REPLAY -> WITNESS -> PACKAGE -> PROMOTE -> OBSERVE -> RECOMPOSE

Hermes is the architecture and reasoning layer.
OpenClaw is the execution and tool layer.
EVEZ Spine is the provenance layer.
CAIN is the contradiction layer.
Invariance testing is the adversarial layer.

Repository names and descriptions are heuristics. They do not establish that a repository works, is secure, is maintained, or can perform a named capability.

The next probe is source inspection and isolated execution.
