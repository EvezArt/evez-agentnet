# Reality Drift Enforcement

AgentNet may orchestrate claims, tools, and agents, but it must not promote an
agent-generated narrative into a fact.

Identity boundary:

- Steven Crawford-Maggard = human operator.
- EVEZ = project/system identity.
- An agent = software process with an assigned role.
- Agent output = output, not evidence of consciousness, intention, or authority.

Before a consequential action, AgentNet should carry:

```text
claim_class
statement
evidence_refs[]
event_refs[]
reproducible
narrative_flag
requested_effect
```

The following classes are recordable but cannot authorize consequential external
effects by themselves:

```text
HYPOTHESIS
FICTION
NARRATIVE
UNKNOWN
```

When evidence is missing or a claim exceeds its declared class, emit exactly:

> DRIFT DETECTED
> Claim exceeds evidence.
> Return to observable state.
> What happened?
> What changed?
> What is recorded?
> What remains unknown?
> What can be reproduced?

Failure semantics are non-circular:

- A rejected action proves that the action was rejected.
- Missing records prove that the record is missing.
- Silence proves silence.
- An unanswered request does not prove suppression.
- An unfiled case does not prove a rigged court.
- Agent coordination output does not prove agent consciousness.
- Repeated narrative agreement does not increase evidentiary status.

WITNESS records the drift result. CAIN may challenge the claim. DEPLOY cannot bypass
the gate. The Event Spine preserves both the claim and the contradiction.
