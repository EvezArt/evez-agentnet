# Acquisition drafts

These drafts use only capabilities that are directly represented by the public EVEZ AgentNet surface. They deliberately avoid invented years of experience, client names, revenue claims, or unverified ERP credentials.

## 1. Senior AI Automation / Backend Engineer — observed budget USD 6,000

Source:
https://www.upwork.com/freelance-jobs/apply/Senior-Automation-Backend-Engineer_~022097980791420533349/

Draft:

I build evidence-oriented AI automation systems with Python, API integrations, workflow orchestration, structured state, and auditability as first-class concerns.

The relevant part of your project is the full business pipeline rather than a chatbot: ingesting structured and unstructured inputs, extracting data, validating it against business rules, routing exceptions, integrating external systems, and preserving an auditable event trail.

My current EVEZ AgentNet work includes an append-only economic event spine, deterministic opportunity normalization, capability/provenance records, contradiction-aware state handling, and automation infrastructure designed around explicit verification boundaries.

I would approach the project as a staged delivery:
1. input and extraction contracts;
2. validation and exception rules;
3. external-system integration boundaries;
4. approval and confirmation workflow;
5. audit/event trail;
6. tests for failure and contradiction cases.

I would keep model output subordinate to deterministic validation and make the system observable enough to diagnose bad extraction, pricing, inventory, or routing decisions.

Relevant public work:
https://github.com/EvezArt/evez-agentnet

I would confirm the exact ERP, data formats, integration constraints, and acceptance criteria before committing to scope.
