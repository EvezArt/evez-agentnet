# Economic capability surface

These are capability declarations, not claims of guaranteed earning power.

| Capability | Current evidence boundary | External action |
|---|---|---|
| Public opportunity observation | Internet Surface Engine records bounded public observations | No automatic outreach |
| Opportunity normalization | `tools/opportunity_engine.py` creates deterministic acquisition records | Human approval |
| Economic event ledger | `tools/economic_spine.py` hashes and chains economic events | No automatic transactions |
| Economic reduction | `tools/economic_reducer.py` separates proposed, contracted, invoiced, received, and cost amounts | Read-only |
| Offer drafting | Acquisition records can identify an offer-draft next action | Human approval |
| Contract/invoice/payment state | Schema and ledger support the states | External systems required for observed evidence |

An opportunity is not revenue. A proposed amount is not a payment. A repository capability is not a buyer commitment.
