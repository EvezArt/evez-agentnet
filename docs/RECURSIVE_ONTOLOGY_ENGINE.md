# EVEZ Recursive Ontology Engine

The engine gives unresolved surfaces a place to expose failures in the categories used to describe them.

REALITY -> WITNESS -> MODEL -> TEST -> FAILURE / CONTRADICTION -> ONTOLOGY BREAK -> COMPETING SUCCESSOR CANDIDATES -> DISCRIMINATORS -> OBSERVATION -> MODEL REVISION

The old model remains an ancestor. A candidate successor is never silently promoted.

Every candidate records the ontology break, prior model, observation, failed representation, proposed distinction, discriminator, falsification condition, evidence references, dependency references, and optional audit reference.

Candidate authority is local to the claim. It is not a grant of access, permission, capability, or control.

The audit-of-audit layer checks whether self-audit findings have traceable evidence and test mappings. It is another inspectable witness, not an oracle.

Representation pressure records repeated exceptions, contradictions, failed tests, and unresolved boundaries as components. It emits no synthetic intelligence score and no invented probability. Pressure means only: consider testing whether the representation is inadequate.

Authority attaches to individual claims and surfaces, not to the system globally. The engine can state that a claim has specified evidence and tests. It never promotes that into global authority.

External actions remain subject to existing authorization, capability, provenance, and observed-effect boundaries. Bypass means bypassing an inadequate representation, not bypassing a security boundary.
