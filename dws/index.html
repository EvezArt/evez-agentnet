Accepted CSV schema

Required: timestamp,metric,value. Optional: source,domain,event_id,note.

Timestamps should be ISO 8601 (preferably UTC, e.g. 2026-10-10T18:00:00Z). Each row is one metric observation.

Suggested metrics: request_rate, latency_ms, error_rate, post_velocity, amplification_ratio, coordination_score, attention_persistence_min, correction_reach_ratio. Define units and collection method in your source notes.

Local-first prototype · No login, tracking pixel, or external telemetry. This tool detects statistical deviations and exploratory associations; it does not identify people, infer intent, establish causation, or receive live platform data automatically.
